## §1 国际对标要点（我们从对标库继承了什么）

| 对标库 | 惯例 | 采纳为 |
|---|---|---|
| mathlib | 模块 docstring 置顶、一句话数学使命 | A 区头部「使命行」 |
| mathlib | 声明 docstring 陈述数学内容，**不含证明叙事** | C 区声明注释 |
| mathlib | 章节横幅 `/-! ## 数学主题 -/` | B 区横幅=数学主题名 |
| mathlib | 文风=数学陈述句、量词显式、禁实现流水 | §3 语气规范 |
| stdlib | `(** … *)` 可提取文档注释 | 关键定理声明注释用 `(** … *)` |
| stdlib | `(*b … *)` 标记证明性注释（非文档） | 证明段落注释统一 `(* … *)`，文档性内容升 `(** … *)` |

**核心原则（mathlib 提炼）**：注释回答「**这是什么数学**」，不回答「**我们是怎么干活的**」。工程过程记录（席次、日志、坑卡、预算）的归宿是 attn 报告与经验卡，**永不进源件注释**。

## §2 三区制结构规范

**A 区·文件头**（`(* ===…=== *)` 边框内，字段固定顺序，缺失字段整行省略）：
```
① 模块名 + 数学使命一句话（"本件形式化 X 的 Y 性质"）
② 依赖清单（Require 的本库件，一行）
③ 对标行（mathlib/stdlib 对应物名称；无则省略）
④ 构造性注记一行（Set 层承载 / 零承认 / 可提取）
⑤ 编译配方一行（9.1 直调、cpu_guard）
⑥（可选·外部投递件）许可与归属行一行（本包自身归属/许可；禁逐字复制 Rocq/INRIA/CNRS 版权盒与官方 WARNING 免责语）
```
剔除：席次战役流水、日志路径、坑卡引用、预算耗时、探针说明、修订历史。

五字段英文名对照（v1.10 增补·源=官方规范标定书-20261023 冲突 2）：①Mission ②Dependencies ③References ④Constructivity ⑤Build——**提交面/投递模块用英形字段名**（官方 7 件与包内范本 4 件实证全英形），中文形限内部沙箱件；gate4 英文别名机检候 L1 提案落地，落地前英文件五字段以人工核对单顶替并响亮登记（禁静默假绿）。

**Statement provenance 外置律（v1.10 增补·源=官方规范标定书-20261023 冲突 6）**：语句级迁移出处账（Statement provenance 迁移对表）属过程性内容，外置于随稿补充材料/伴生文档，**禁入投递库件**；库内仅留 References 名级出处（fully qualified name，行号至多括注辅助）。

**B 区·章节横幅**：`(* ================= §n <数学主题名> ================= *)`——主题用数学内容命名（如「一致凸性与最近点投影」），**禁**战役名/席名/「第一部分」类空洞名。提交面/投递模块合法变体：`(* ==== Section n. <math topic> ==== *)` 英文形（v1.10 增补·源=官方规范标定书-20261023 冲突 7——包内范本已定型英文形，§ 形国际读者不识）。

**C 区·声明与证明注释**：
- 定理/引理声明注释（鼓励 `(** … *)`）：数学陈述的白话复述 + 证明策略一句话（"对 n 归纳"、"由三角不等式直接推得"）。
- 证明段落注释：每步写**数学理由**，引用**真实标识符名**（如 `由 mult_comm`）；提交面/投递模块步进注释默认英文陈述句，中文限内部沙箱件（不入对外投递面）（v1.10 改裁·源=官方规范标定书-20261023 冲突 1）。
- 证明注释名（注释中对证明件/情形的称呼）：须用规范数学表述（§4 映射表）；情形分析写「情形 n=0 / 情形 n=S n'」，归纳写「归纳步：由 n 到 S n」。

**注册面文本域（v1.3 扩注）**：order.txt 稳定标识列注释与 UpReqIndex.v ng_ 块描述注释纳入注释卫生域，同吃注释审校（判例：UpReqIndex 双树 ng_ 块「同车/放电/定谳/台账」42 笔审校红，`attn/_tab28_IDX清洗重认证回执-20260929.md`）；清洗时注册数据零触碰（ng_ 语句名/meta 值/行数/md5 锚值一个字符不改），仅注释词面按 §4 映射改写。

## §3 语气与用词规范

**禁**（出现在任何注释即不合格）：
1. 工程比喻：承重墙、接线、拍平、打包、总装、垫片、流水线、挂账、收割、翻牌……
2. 过程流水：席次编号、日期战报、日志/坑卡文件名、预算耗时、对战纪要。
3. 口语与拟人：「搞定」「直接抄」「让它自己收敛」「这个家伙」。
4. 承认式英文字面：admit/axiom/parameter/conjecture/abort/hypothesis 词面（G1 注释轨 0 容忍）。
5. 自贬或夸饰：「trivial」「显然」「轻而易举」「惊世骇俗」——数学强度让定理陈述自己说话。
6. 工程隐语过程语（v1.3 补）：「化石／冰川／闸门／红温／停推」等过程语——按语境改「未清偿历史缺陷件／长时验证件／机器检查门／高温状态／推送阻断」或径删。

**推荐**：陈述句数学事实；量词与前提显式（"对任意行随机核 K，若…则…"）；符号统一（乘 `·` 或并列、蕴含 `⟹`、等价 `⟺`、任意 `∀`、存在 `∃`、映射 `→`）。

## §5 证明注释名规范（本役重点）

1. 注释中指称任何定理/引理/定义，**必须用源码真实标识符**（`mtw_tv_exact_iter`），不得另造绰号。
2. 证明策略命名对齐国际惯例：归纳（induction）、情形分析（case analysis / 分情形）、反证（仅经典段禁用，本库构造性语境写「反设」并立即构造见证）、 witnessed construction（见证构造）、reduction（归约）。
3. 中间断言（assert/claim）在注释中给出数学身份：「中间断言：演化后逐点等于首行」。
4. 同一事实在多处注释中的称呼必须一致（全局一致性检查入二轮复审）。

## §6 与闸门的联动

- G1 注释轨禁词 ⊂ 本规范 §3.4；注释规范化后 G1 双轨仍须 0/0。
- 本规范只动注释：**每件改前/改后必须通过嵌套注释剥离逐字节相等验证**（剥离脚本见指南卡第 4 步）——这是「零语义变更」的机械凭证。**行数不变量（T1/T2 席双实证）**：剥离算法保留每行行尾换行，故注释修订必须**逐行 1:1 只换注释文本**，不得增删或合并行；跨行重排头部时保持总行数与换行位置不变。行间换行与注释行首缩进属代码面字节，逐区守恒（T4 席实证）；**行尾 CR 守恒**——CRLF 件编辑必须逐行保留 `
`（T10 席实证：丢 CR 被剥离相等门拦截后从备份还原重做）。
- **词法陷阱（T3 席实证）**：Rocq 9.1 将紧随句点的 `(*` 词法化为项层投影（`.(*`）——注释不得紧跟句点，句点与注释间须有空白；编译门可拦截，剥离相等门不设防。
- **紫层轨判读（T4 席裁决案）**：注释中按真名引用标识符（如 `real_lt_plus_compat`）不算紫层新增——紫层轨禁的是 Prop 层类型泄露，非标识符引用；G1 记录时注明「标识符引用豁免」。

- **注释审校机械仲裁（v1.3 增补）**：以库内 canonical 脚本 `scripts/gates/gate4_comment_guard.py` v2.1 EXT（`--tree` 双树扫描）为唯一词表仲裁——FAIL=0/hard=0 强制，REVIEW 黄档登记放行；交付包须随附 gate4＋gate1 双扫描回执。判例：外部交付包 20/20 新伤红 312 hard——包方自检词表与 canonical 不同轨（`attn/_tab2_机检三闸报告-20260928.md`）；消融包清洗 246 hard→0，剥注释 token 面 md5 双向相等留档为「零语义变更」机器凭证（`attn/_tab7_预清洗报告-20260928.md`）——与上文剥离相等门口径衔接。
