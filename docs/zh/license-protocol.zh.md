## 一、工具替你做什么

rocqwash 是仓库卫生与持续集成工具集。各面读取仓库与 CI 状态、产出判读与报告；
仅在操作者明确开启时才**行动**：带盯守的推送（pushci）、预算帽内的失败作业重派
（自愈腿）、以及只动注释面的机械修复（autofix 腿，编辑类别为桌面核定表）。
每个行动面都有预算帽，每个结果都带指纹号写入仓内经验台账——任何一次自主行动
都可事后审计。

## 二、操作者授权什么

由操作者决定：(a) 工具指向哪些仓库；(b) 用什么凭据与作用域（令牌读自操作者
自身配置，绝不内嵌）；(c) 联网面是否可达（`ROCQWASH_MCP_ALLOW_NET=1` 开启，
默认拒绝）；(d) 行动面是否接入 CI。授予仓库写作用域是操作者的显式行为；
工具集不做超预算、超作用域、无台账的写。

## 三、自主行动三铁界

一为**预算帽**：每个 CI run 自动重跑至多一次；每支每修复类至多两轮；被取消
的 run 至多复活一次；帽从盘面状态文件执行，操作者可读可重置。二为 **fail-loud**：
盯守或修复腿自身坏掉就显示红；底层 CI 的红是数据，不是工具可以吞掉的错误。
三为**编辑类别白名单**：自动修复只动核定表列名的注释面类别；语句体与证明体
按构造排除在外。

## 四、数据与台账

经验台账（`docs/exp-ledger.jsonl`）记录工具行为与判读，含仓名、run 号、判读
摘要；不得喂入机密（令牌由处理它的工具脱敏，脱敏报告即工件面）。将台账镜像
到公开面前，操作者有先行审读的责任。

工具集按 AGPL-3.0 第 15–17 条的担保与责任条款提供：「按现状」无任何
担保；在法律允许范围内对使用产生的损害（含操作者开启的自主行动所致）
不承担责任。预算帽与审计台账的用途，正是让操作者在开启前就能限定并审计
工具会做什么。
